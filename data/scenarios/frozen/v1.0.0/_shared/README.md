# Frozen Scenario Shared Fixtures

These files contain references and common controlled-fixture definitions used by the P3-03 scenario bundles.

- All opportunity and document content is synthetic or explicitly marked as a frozen public/reference fixture.
- No credential, confidential client information, or real personal information is included.
- Fault-injection fixtures are evaluation controls, not claims about live production failures.
- Expected outcomes are targets and remain unexecuted until later implementation and evaluation.
