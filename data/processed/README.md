# Processed Data

This directory is reserved for generated normalized or derived data.

Processed artifacts must be reproducible from documented source inputs, configuration, and code. They are not treated as independent authoritative sources.

For the final Project 7 evidence chain, most committed evaluation products are under [`../../outputs/evaluation/`](../../outputs/evaluation/) rather than here.

Do not place credentials, confidential client information, or uncontrolled manual edits in processed artifacts.
