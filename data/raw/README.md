# Raw Data

This directory is for preserved public or explicitly approved source inputs used by the capstone prototype.

For each retained source, record or preserve as applicable:

- source URL or source identity;
- retrieval/acquisition date;
- version/effective date when available;
- checksum;
- use limitation or provenance note.

Project 7 also uses bounded registered reference assets under [`../reference/`](../reference/), including FAR and Project 2 historical-procurement material.

Do not commit credentials, confidential client data, or unapproved personal information.
